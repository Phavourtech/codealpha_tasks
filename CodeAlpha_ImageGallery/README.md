# CodeAlpha Image Gallery

A responsive image gallery built using HTML, CSS, and JavaScript for the CodeAlpha Frontend Development internship task.

## Features

- Responsive image gallery layout
- Lightbox image preview
- Next and previous image navigation
- Image category filters
- Hover effects and smooth transitions
- Works on desktop, tablet, and mobile screens

## How to Run

1. Download or clone the project.
2. Open `index.html` in a browser.
3. No installation is required.

## Technologies Used

- HTML
- CSS
- JavaScript
